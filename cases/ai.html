PROJECT 01

Heart in Deck · Godot 프로토타입

기획 데이터를
실제 전투에 연결하기

엑셀에서 관리하는 적 정보와 행동 패턴, 웨이브 구성을 게임에 연결했습니다. 여러 적이 함께 등장하고, 모두 쓰러뜨리면 다음 웨이브로 진행하는 전투 구조를 구현했습니다.

기획에서 정한 전투 규칙이 데이터와 실행 화면에서 함께 확인되도록 구성했습니다.
  1. 기획 데이터엑셀적 · 행동 · 웨이브
  2. 데이터 연결내보내기 · 검증참조와 입력 규칙 확인
  3. 플레이 확인Godot 전투대상 선택 · 웨이브 진행

AI와 함께 구현한 범위

데이터 변환과 검증 코드, 적별 체력·상태 관리, 공격 대상 선택과 웨이브 전환을 구현했습니다. 화면에는 적의 다음 행동과 공격 대상, 현재 웨이브를 표시했습니다.

구현과 확인

적 데이터와 웨이브 구성을 전투에 연결하고, 대상·상태·턴 전환 등의 규칙을 확인하는 검증 코드와 실행 화면을 확보했습니다.

PROJECT 02

물 마시기 기록 · 웹앱

생활 기록과 보상을
하나의 흐름으로 연결하기

물을 마신 양을 기록하고, 누적량에 따라 보상 놀이에 참여할 수 있도록 만들었습니다. 섭취량 입력부터 오늘의 진행도, 룰렛 참여와 날짜별 기록까지 이어지는 흐름입니다.

기록

양 입력과 진행도 확인

빠른 입력 버튼과 직접 입력으로 마신 양을 기록하고, 오늘의 목표 진행도를 표시합니다.

보상

누적량과 룰렛 연결

300mL마다 룰렛 기회를 얻고 하루 최대 3회까지 참여합니다. 결과는 오늘 받은 보상으로 남깁니다.

  1. 입력물 마신 양 기록빠른 입력 · 직접 입력
  2. 규칙300mL마다 기회하루 최대 3회
  3. 결과룰렛 · 기록 저장보상 내역 · 날짜별 달력

AI와 함께 구현한 범위

섭취량 입력, 목표 진행도, 날짜별 달력과 보상 룰렛을 구현했습니다. 오늘 사용한 룰렛 횟수와 보상 내역을 브라우저에 저장하고, 날짜가 바뀌면 새 하루의 기록으로 진행하도록 연결했습니다.

결과물

오늘의 물 기록과 보상 결과, 날짜별 기록을 저장하는 웹앱입니다. 생활 기록을 보상 참여와 연결하는 기능을 구현했습니다.

PROJECT 03

옷장·인형놀이 · 웹 시제품

꾸민 캐릭터와
계속 놀 수 있는 화면 만들기

캐릭터의 옷과 악세서리를 고른 뒤, 꾸민 캐릭터를 무대에서 움직이며 놀 수 있도록 만들었습니다. 캐릭터 선택, 꾸미기와 저장, 무대 배치까지 이어지는 웹 프로토타입입니다.

AI와 함께 구현한 범위

옷·악세서리·배경 변경, 코디 저장과 무대 배치를 구현했습니다. 여러 친구를 함께 배치하고 각각 움직이거나, 현재 배치를 단체 사진으로 저장하는 기능까지 연결했습니다.

꾸미기

선택한 코디 저장

캐릭터별로 코디를 보관하고, 다음 놀이에서도 불러올 수 있도록 구성했습니다.

놀이

여러 친구를 무대에 배치

친구별 위치와 앞뒤 순서를 저장하고, 현재 무대를 단체 사진으로 남깁니다.

결과물

꾸미기와 인형놀이를 직접 조작해볼 수 있는 웹 시제품입니다. 화면과 인터랙션을 통해 놀이 흐름을 구체화했습니다.
