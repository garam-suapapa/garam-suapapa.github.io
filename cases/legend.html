CASE 01

충전 방식을 나눠
보유 구조를 명확하게

보유량을 비우려고 접속 시간을 맞추는 부담을 줄이기 위해, 충전 스태미너와 예비 스태미너를 나누는 구조를 설계했습니다.

담당 작업

  • 자동 충전과 추가 충전의 보유 구조를 분리했습니다.
  • 최대치 이후 충전분의 별도 보유 규칙과, 다음 충전 시간·충전 중지 상태의 표시를 정의했습니다.
CASE 02

추천 팀 편성을 활용한
게임 가이드

팀 구성 기준을 모르는 유저가 다른 유저의 클리어 편성을 참고하고 자신의 팀에 적용할 수 있도록 설계했습니다.

담당 작업

  • 최근 해당 스테이지를 클리어한 덱을 기준으로 전투력이 낮은 편성을 보여주는 선정 규칙을 정의했습니다.
  • 전투 데이터 스냅샷으로 편성 정보를 제공하고, 선택한 추천 팀을 자신의 편성에 복사하는 흐름을 설계했습니다.
CASE 03

시즌별 도전과 성장을 연결한
기억의 경계

콘텐츠·시스템 설명

시너지 스톤의 주요 파밍처인 경계의 유적과 기억의 저장소를 시즌형 도전·성장 구조로 연결했습니다. 시즌마다 참여 가능한 에피소드 영웅이 달라지고, 스테이지 진행에 따라 반복 던전과 전용 성장이 열립니다.

스테이지 도전 → 기억의 저장소에서 재화 획득 → 성장 노드 강화 → 다음 난이도 도전으로 순환합니다. 시즌이 끝나면 진행 상태와 전용 성장을 초기화하도록 정의해 다음 시즌의 편성과 성장 목표를 다시 준비하게 했습니다.

담당 작업

  • 시즌별 참여 영웅, 진행 순서와 종료 시 초기화 규칙을 정의했습니다.
  • 스테이지 진행에 따라 기억의 저장소를 개방하고, 파밍 재화를 전용 성장에 사용하는 순환 구조를 설계했습니다.
  • 성장 노드의 선행 조건·효과·비용과 시즌·스테이지 데이터를 정의했습니다.
CASE 04

가입부터 일상 참여까지
길드 시스템의 상태와 권한 설계

콘텐츠·시스템 설명

길드 생성과 가입부터 역할별 운영 권한, 출석과 길드 성장까지 일상 참여에 필요한 규칙을 설계했습니다. 유저가 길드를 찾고 합류한 뒤 꾸준히 참여하는 흐름을 구성했습니다.

가입 방식·정원·대기 상태에 따라 목록과 가입 행동을 구분하고, 길드장·부길드장·길드원에게 서로 다른 운영 권한을 부여했습니다. 개인 출석은 보상과 길드 경험치로 이어지고, 누적 경험치가 길드 레벨과 콘텐츠 해금으로 연결됩니다.

담당 작업

  • 자동 가입·승인 가입·가입 불가와 가입 대기·재가입 상태를 구분했습니다.
  • 길드장·부길드장·길드원의 초대, 가입 승인, 추방과 권한 위임 범위를 정의했습니다.
  • 개인 출석의 보상·길드 경험치와 길드 레벨별 누적 경험치, 콘텐츠 해금을 연결했습니다.
CASE 05

두 팀의 전투를
길드의 시즌 점수로 연결

콘텐츠·시스템 설명

길드원이 보스에 도전하고 개인 기록을 길드의 시즌 점수로 모으는 콘텐츠입니다. 시즌 일정, 전투 진입과 편성, 개인 기록·길드 랭킹, 보상 수령까지 하나의 흐름으로 기획했습니다.

별도로 작성한 2팀 전투 수정안에서는 선발팀 전투 후 결과 화면을 거치지 않고 후발팀 전투로 이어지도록 확장했습니다. 후발팀은 전투 정보와 보스 상태를 초기화해 시작하고, 최종 결과에서 합산 점수와 팀별 리포트를 함께 확인하도록 구성했습니다.

담당 작업

  • 시즌 일정, 개인 기록과 길드 합산 랭킹, 개인 달성·길드 랭크 보상을 정의했습니다.
  • 2팀 전투 수정안에서 선발·후발팀의 영웅 중복을 제한하고, 팀 전환 시 전투 정보와 보스 상태를 초기화하도록 설계했습니다.
  • 두 팀의 점수 합산과 팀별 데미지 리포트, 편성·점수·보상 데이터 구조를 정리했습니다.
CASE 06

70레벨 이후 성장을 위한
계정 단위 레벨 확장

콘텐츠·시스템 설명

70레벨 이후의 성장 목표와 잉여 재화 소비처를 마련하는 시스템입니다. 계정 단위로 성장 효과를 적용해 영웅마다 반복 육성하는 부담을 줄이고자 했습니다.

열린 범위 안에서 레벨을 올리는 레벨 증가와, 다음 최대 레벨을 여는 레벨 돌파를 구분했습니다. 정수 해방으로 노드의 능력치를 얻고 조건을 채우면 다음 성장 단계를 개방하도록 연결했습니다. 레벨·노드별 조건과 비용, 잠금 상태에서도 확인할 수 있는 다음 목표를 함께 정의했습니다.

담당 작업

  • 최대 레벨을 여는 레벨 돌파와, 열린 범위에서 레벨을 올리는 레벨 증가를 구분했습니다.
  • 정수 해방으로 성장 노드의 능력치를 얻고, 한계 돌파로 다음 최대 레벨과 노드 단계를 확장하도록 설계했습니다.
  • 레벨·노드별 해금 조건, 효과와 재료 비용을 데이터로 정의하고 잠금·성장 가능 상태의 안내를 정리했습니다.
