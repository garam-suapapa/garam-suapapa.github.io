CASE 01

일상 플레이를
이벤트 참여로 연결

별도의 진입 동선이 필요한 이벤트는 참여 과정 자체가 부담이 될 수 있습니다. 일반 플레이 안에서 미션이 자연스럽게 진행되고 보상으로 이어지도록 구조를 설계했습니다.

일차별로 미션을 열어 접속 루틴을 만들고, 기존 콘텐츠의 플레이가 이벤트 조건을 충족하도록 구성해 별도의 반복 행동을 줄이는 방향입니다.

이벤트를 독립된 활동으로 분리하지 않고, 기존 플레이 동선과 미션·보상을 연결했습니다.
설계 목표

일상 플레이와 이벤트를 연결해 참여 동선을 단순하게 하고 반복 접속의 이유를 제공하는 것을 목표로 했습니다. 실제 참여율 변화는 확인 자료가 없어 기재하지 않았습니다.

CASE 02

웨이브와 역할 분담으로
반복 전투에 변화를

단일 보스를 반복하는 레이드가 단조로워지는 문제를 줄이기 위해, 웨이브 단위로 보스를 순차 등장시키는 구조를 설계했습니다. 웨이브마다 다른 패턴 조합을 구성해 전투 흐름이 달라지도록 했습니다.

고레벨과 저레벨 유저가 서로의 약점을 보완하는 역할 분담도 함께 고려해, 서로 다른 성장 단계의 유저가 같은 콘텐츠에 참여할 이유를 만들고자 했습니다.

설계 목표

웨이브별 전투 변화를 주고 성장 단계가 다른 유저의 참여 범위를 넓히는 것을 목표로 했습니다.

SCOPE

전체 담당 범위

시스템·라이브 개선

  • 일차별 미션이 열리는 이벤트 시스템
  • 지표 데이터와 유저 피드백 기반 불편 요소 발굴
  • 장비 개조 등 기존 시스템 개편안 수립

콘텐츠·이벤트

  • 기존 플레이 동선과 연결한 이벤트
  • 웨이브 기반 레이드 보스
  • 고레벨·저레벨 유저의 협동 구조

신규 직업 검토

  • 기존 스킬·장비·밸런스 데이터 충돌 요소 파악
  • 예외 처리 케이스 정리
  • 출시 전 밸런스 검토
