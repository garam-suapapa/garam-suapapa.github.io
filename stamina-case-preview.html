비교용 예시입니다. 왼쪽은 기존 문구 그대로, 오른쪽은 설명 방식을 보여주기 위한 초안입니다. 오른쪽의 세부 규칙·선택 이유·담당 범위는 임의로 구성했으며, 실제 경력 사실이나 검증된 성과를 뜻하지 않습니다.

충전 방식 분리로
스태미너 보유 규칙 정리

자동 충전의 공급 한도와 추가 충전의 보유 규칙을 구분해, 재화 관리와 유저 편의성을 함께 고려한 설계.

재화 규칙플레이 편의성상태별 예외 처리
01

문제와 목표

기존 설명 재구성

스태미너가 최대치에 도달하면 자동 충전이 중단된다. 충전 손실을 피하려는 유저에게는 보유량을 비우기 위해 접속 시간을 맞춰야 한다는 부담이 생길 수 있다.

이 문제를 출발점으로, 자동 충전과 추가 충전이 하나의 최대치 규칙에 묶여야 하는지 검토하는 사례로 정리했다.

설계 목표: 충전 방식별 보유 규칙을 명확히 하고, 유저가 추가로 확보한 스태미너를 사용할 여지를 넓힌다.

접속 부담이 실제로 감소했는지는 별도 검증이 필요한 효과입니다.

02

설계 기준과 선택 이유

가상 설계 예시
  • 1자동 공급량은 통제한다.
    자동 충전에는 한도를 유지해 시간당 공급 규칙이 흔들리지 않도록 한다.
  • 2추가 충전의 보유 규칙은 분리한다.
    유료 충전분은 자동 충전 한도와 별도로 처리해, 한도에 도달한 상태에서도 추가 확보할 수 있게 한다.
  • 3소모 결과를 예측할 수 있게 한다.
    자동 충전분부터 소모하고 부족한 양만 추가 충전분에서 차감하는 규칙을 일관되게 적용한다.
선택 이유 예시: 전체 최대치를 높이는 대신 충전 방식을 분리하면, 자동 공급 한도를 유지하면서 추가 보유 규칙을 따로 설정할 수 있다.
03

핵심 동작과 화면

가상 규칙 예시
자동 충전분시간 경과에 따라 충전↓한도 도달 시 충전 중단
플레이 입장 시 우선 차감
추가 충전분유료 충전으로 확보↓자동 충전 한도와 별도 보관
자동 충전분이 부족할 때 차감

입장 가능 여부는 두 보유량의 합으로 판단한다. 차감 순서를 고정해 유저가 수동으로 사용할 종류를 고르는 단계를 줄인다.

04

주요 예외 처리

가상 규칙 예시
입장 비용이 10인 상황을 가정한 처리 예시
발생 상황처리 규칙
자동 충전분이 최대치자동 충전은 중단한다. 추가 충전 가능 여부는 별도 규칙으로 판단한다.
자동 6 / 추가 8 보유입장을 허용하고 자동 6, 추가 4를 차감한다. 추가 충전분 4가 남는다.
자동 3 / 추가 4 보유합계가 비용보다 적으므로 입장을 제한한다. 두 보유량 모두 차감하지 않는다.
입장 요청 중복 발생입장 처리와 차감을 한 번만 반영해, 동일 요청에 재화가 중복 소모되지 않도록 한다.

수치와 처리 방식은 문서 구성 비교를 위해 만든 예시입니다.

05

담당 범위와 협업

가정한 담당 범위

06

검증과 결과

확인 전

검증 계획 예시. 최대치 도달 전후, 두 종류를 함께 차감하는 입장, 잔액 부족, 중복 요청을 각각 확인한다. 충전 재개 시점과 화면 표시도 실제 보유 상태와 일치하는지 점검한다.

결과를 적는 기준

이 시안에는 테스트 통과나 지표 개선을 성과로 기재하지 않았다. 실제 적용 여부, 테스트 기록, 유저 반응이 확인되면 그 범위에 맞춰 결과를 추가한다.

‘편의성 향상’은 현재 설계 목표로만 설명합니다. 기존 문구의 ‘접속 압박 해소’는 검증 근거 확인 후 확정할 표현입니다.
